## §1. Context

The engine's Level-2 prune (ADR-0020, Day 15) drops a merged row R at the L0→L1 compaction seam iff a retained R' satisfies `(C1) sysTime(R') > sysTime(R)` AND `(C2) [vs', ve') contains [vs, ve)` AND `(C3) sysTime(R') <= T_gc` — the `(C3)` floor `T_gc` is the transaction-time GC horizon (the load-bearing claw closing the §0.4(ii) txTime-gap silent-data-loss class: a row DROPPED at horizon H1 is in the gap if the horizon retreats to H0 < H1, so the floor is a FLOOR not a high-water, and a live query at txTime < T_gc MUST still see R). Day 15 made `T_gc` an operator-set STATIC knob (`CompactionConfig.PruningHorizonInt64Ns`); the engine NEVER auto-prunes (the operator's retention policy). ADR-0020 §6a named the `T_gc` auto-inference as a P1: the engine should TRACK the observed live-query txTime frontier itself + feed it back into the `(C3)` floor, so the operator's role moves from "guess the frontier" to "set the safety floor + the backoff window." Day 19→20→20.1→21 named it the unblocked next move; Day 21 unblocked it (the OTel-INIT fork made the telemetry honest under a real Meter — the prerequisite). Day 22 IMPLEMENTS it.

The inferrer FLOORS the operator knob (does NOT replace it): `effective = max(operatorFloor, observedFrontier - backoff)`. The operator-set `PruningHorizonInt64Ns` is the HARD floor backstop (the inferrer NEVER admits an effective horizon below it — the §0.a contract; the §0.4(ii) class stays closed); the backoff tolerates forensic queries `backoff` nanoseconds into the recent past (a burst of stale-txTime queries does NOT collapse the floor to the distant past in one pathological query). The monotone clamp is LOUD: `SetInferredHorizon` advances `cfg.PruningHorizonInt64Ns` (the SAME field `DominancePrune` reads at `l1_compactor.go:710` — UNCHANGED) IFF the candidate is STRICTLY GREATER than the current effective; a retreat is REFUSED + counted (`PruningHorizonRetreatRefused`) + logged (the §0.4(ii) class — Day 15 closed it; Day 22 does NOT reopen it). The `DominancePrune` function body is UNCHANGED (Day 22 changes the horizon SOURCE, not the prune).
